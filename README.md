# 🧑‍💻 Office: The Code to the Top

**Однопользовательская 3D игра симулятор с элементами квеста**, в которой игроку предстоит пройти карьерный путь в IT-компании — от стажёра до руководителя отдела.



## 🎯 Описание проекта

**Office: The Code to the Top** — это интерактивная игра на Unreal Engine 5, моделирующая жизнь в офисной среде. Игрок выполняет задания, развивает навыки, взаимодействует с NPC и участвует в мини-играх, чтобы прокачать своего персонажа и добраться до вершины корпоративной лестницы.



## 🛠️ Технологии

- **Unreal Engine 5** — игровой движок
- **Blueprints** — реализация логики игры
- **Widget Blueprints** — интерфейсы пользователя
- **NavMesh, TriggerBox, LineTrace ...** — механики взаимодействия

## Основной функционал

- Карьерная прогрессия: Стажёр → Junior → Middle → Senior → Руководитель
- Прокачка характеристик: Харизма, Квалификация, Продуктивность
- Внутриигровой магазин: курсы, предметы, аксессуары
- Сюжетные уровни и мини-игры
- Диалоговая система

- Мини-карта и физика объектов

## 📊 Текущий этап реализации

На данный момент завершена работа над MVP-версией игры. Реализованы ключевые функции:

- Продуманный мир - приблеженный к реальному офису
- Уровни: «Горящие дедлайны», «Все по полочкам», «Ранние выходные»
- Система прокачки характеристик (харизма, квалификация, продуктивность)
- Внутриигровой магазин с проверкой условий покупок
- Основной интерфейс (главное меню, настройки, пауза, HUD)
- Мини-игра «Резиновая уточка»
- Мини-карта, управление от первого и третьего лица
- Физика и анимация взаимодействий с объектами
- Диалоговая система и зоны появления подсказок
